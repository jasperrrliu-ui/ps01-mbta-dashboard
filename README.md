# The Most Fragile T Commutes

A data dashboard about historical MBTA subway service disruptions and performance, built for PS01: Agentic Computing Apprenticeship.

## Research question

Across a documented historical period, which MBTA subway lines, stations, and transfer points show the strongest delay signal, and how does observed performance vary by hour of day?

The project is for Boston riders and transit advocates. It will not predict an individual rider's exact delay.

## Project stages

1. Verify official public datasets and their fields.
2. Download a bounded historical sample and preserve its provenance.
3. Perform exploratory data analysis before selecting final dashboard metrics.
4. Build a responsive dashboard from validated findings.
5. Publish the site and document methods, limitations, and sources.

See [deliverables/data-plan.md](deliverables/data-plan.md) for the data contract.
